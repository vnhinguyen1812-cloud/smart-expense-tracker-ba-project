# Smart Expense Tracker - Business Analyst Project

## Project Overview

This project simulates a fintech personal finance management system designed to help users track expenses, monitor spending behavior, and manage monthly budgets through automated budget alerts.

The project was developed as a Business Analyst mock project focusing on:
- business analysis
- requirement gathering
- process modeling
- SQL analysis
- dashboard visualization
- wireframe design

---

## Business Problem

Many users struggle to manage personal finances effectively due to:
- lack of spending visibility
- poor budgeting habits
- limited financial tracking tools
- absence of real-time budget alerts

This often leads to overspending and low financial awareness.

---

## Proposed Solution

The Smart Expense Tracker system helps users:
- track transactions
- categorize expenses
- set monthly budgets
- monitor spending behavior
- receive budget alerts
- visualize financial activities through dashboards
